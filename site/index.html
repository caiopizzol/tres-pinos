A tomada brasileira para agentes de IA: conectores que dão acesso ao que só existe no Brasil, e skills que ensinam o que fazer com ele.

Começar GitHub
  • Leem por padrão.Pagar boleto e emitir nota ficam desligados. Ligados, cada um espera a sua aprovação, numa página do conector.
  • No seu servidor.Com o seu certificado e a API oficial de cada sistema. Nenhuma empresa no meio.
  • Você decide.O agente lê, confere e prepara. Nada é pago nem emitido sem a sua chave.

Ligar o banco e a NFS-e

$ mkdir tres-pinos && cd tres-pinos
$ curl -fsSLO https://github.com/caiopizzol/tres-pinos/releases/latest/download/compose.yaml
$ curl -fsSL https://github.com/caiopizzol/tres-pinos/releases/latest/download/env.example -o .env
$ sed -i.bak 's/^COMPOSE_PROFILES=.*/COMPOSE_PROFILES=inter,nfse/' .env
$ docker compose up -d   # depois de preencher o .env
