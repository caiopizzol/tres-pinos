nenhum adaptador.

A tomada brasileira para agentes de IA: conectores MCP de código aberto, que você hospeda, para ler WhatsApp, boletos, Pix e a sua conta no Sicoob.

Começar GitHub

Por que três pinos?

Em 2011 o Brasil tornou obrigatória a sua própria tomada. Quase nenhum outro país usa. A imprensa chamou de padrão jabuticaba: aquilo que só dá aqui.

Boleto, Pix, CPF para tudo e cliente que só fala por WhatsApp também são jabuticabas. Os agentes de IA chegam prontos para o resto do mundo e travam nelas.

Aviso. O conector do WhatsApp usa o WhatsApp Web por meio do WAHA, que não é oficial. Um número conectado assim pode ser banido. Este projeto não tem relação com o WhatsApp nem com a Meta.

Começar

  1. Suba os serviços

    Precisa do Docker. Gere cada senha e chave do .env com openssl rand -hex 32.

    $ git clone https://github.com/caiopizzol/tres-pinos
$ cd tres-pinos && cp .env.example .env   # preencha as senhas e chaves
$ docker compose up -d

  2. Conecte o seu número

    Leia o QR no painel do WAHA, em http://127.0.0.1:3010/dashboard/.

  3. Ligue o seu agente

    Na mesma máquina:

    $ export WHATSAPP_KEY=...   # a mesma do .env

    Claude Code

    $ claude mcp add --transport http whatsapp http://127.0.0.1:3011/mcp \
    --header "Authorization: Bearer $WHATSAPP_KEY"

    Codex

    $ codex mcp add whatsapp --url http://127.0.0.1:3011/mcp \
    --bearer-token-env-var WHATSAPP_KEY

    Sicoob

    Inclua sicoob em COMPOSE_PROFILES e ligue o agente em http://127.0.0.1:3012/mcp, com Authorization: Bearer $SICOOB_KEY. O certificado e o resto estão em como configurar.

    De outra máquina

    Por enquanto, só o WhatsApp: para apps na internet, com login, veja o acesso pela internet.
