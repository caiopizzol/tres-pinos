A tomada brasileira para agentes de IA: conectores MCP de código aberto, que você hospeda, para o que só existe no Brasil.

Começar GitHub

Por que três pinos?

Em 2011 o Brasil tornou obrigatória a sua própria tomada. Quase nenhum outro país usa. A imprensa chamou de padrão jabuticaba: aquilo que só dá aqui.

Boleto, Pix, CPF para tudo e cliente que só fala por WhatsApp também são jabuticabas. Os agentes de IA chegam prontos para o resto do mundo e travam nelas.

Conectores

sicoob só lê, nunca movimenta dinheiro
Ferramenta O que faz Precisa de
get_balance Lê o saldo e o limite da conta corrente. e-CPF A1
get_statement Lê as transações de um mês. O Sicoob guarda só os últimos três. e-CPF A1
inter só lê, nunca movimenta dinheiro
Ferramenta O que faz Precisa de
get_balance Lê o saldo e o limite da conta PJ. Inter Empresas
get_statement Lê as transações de um mês. Inter Empresas
nfse só lê, nunca emite nem cancela notas
Ferramenta O que faz Precisa de
list_invoices Lê as notas fiscais de serviço da empresa e os cancelamentos, no sistema nacional. e-CNPJ A1
  • Pela API oficial de cada banco: no Sicoob, com o seu certificado e-CPF A1; no Inter, com o certificado da integração. Como configurar o Sicoob e o Inter.
  • Pagamentos são recusados antes de chegar ao banco, mesmo que o certificado permita.
  • Notas fiscais de serviço pela distribuição oficial do sistema nacional, com o certificado e-CNPJ A1 da empresa. Emitir e cancelar notas é recusado do mesmo jeito. Como configurar a NFS-e.

Começar

  1. Baixe o repositório

    Precisa do Docker.

    $ git clone https://github.com/caiopizzol/tres-pinos
$ cd tres-pinos && cp .env.example .env   # preencha as variáveis

  2. Prepare o certificado

    Veja como configurar o Sicoob, o Inter ou a NFS-e.

  3. Suba o conector

    Gere a chave do .env com openssl rand -hex 32.

    $ docker compose up -d

  4. Ligue o seu agente

    Na mesma máquina, com a chave do .env no ambiente em que você abre o agente. Os comandos guardam só o nome da variável.

    Conector Porta Chave
    sicoob 3012 SICOOB_KEY
    inter 3013 INTER_KEY
    nfse 3014 NFSE_KEY

    Para o Sicoob; para os outros, troque o nome, a porta e a chave.

    $ export SICOOB_KEY=...   # a mesma do .env

    Claude Code

    $ claude mcp add --scope user --transport http sicoob http://127.0.0.1:3012/mcp \
    --header 'Authorization: Bearer ${SICOOB_KEY}'

    Codex

    $ codex mcp add sicoob --url http://127.0.0.1:3012/mcp \
    --bearer-token-env-var SICOOB_KEY
