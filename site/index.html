Três pinos,
nenhum adaptador.

Ferramentas e skills para os seus agentes de IA trabalharem numa empresa brasileira: banco, nota fiscal e conta para pagar. Código aberto, num servidor seu.

Começar GitHub
  • Só leem.Pagar e emitir nota são recusados no conector, mesmo que o certificado permita.
  • No seu servidor.Com o seu certificado e a API oficial de cada sistema. Nenhuma empresa no meio.
  • Você decide.O agente lê, confere e sugere. Quem paga e quem emite é você.

Sem certificado · ler uma conta

$ git clone https://github.com/caiopizzol/tres-pinos
$ cd tres-pinos && export TRES_PINOS_DIR="$PWD"
$ bun install --production --filter @tres-pinos/boleto
$ mkdir -p ~/.claude/skills && cp -R skills/ler-conta ~/.claude/skills/

Com certificado · ligar o banco e a NFS-e

$ cp .env.example .env   # COMPOSE_PROFILES=inter,nfse
$ docker compose up -d
